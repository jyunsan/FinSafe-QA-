### 【v1.0】评测集难度分级说明

本难度分级仅从“自然语言问题生成 SQL 查询语句”的复杂度出发进行评估，不考虑业务分析、结果解释或金融专业知识难度。

#### 分级核心原则

- **1级：直接查**
- **2级：需要统计计算**
- **3级：需要多步 SQL 逻辑拆解**

该分级主要用于评估：

- Text2SQL 任务难度
- SQL 自动生成能力
- 数据集构建与模型训练复杂度
- SQL Agent 推理能力要求

#### 1级（简单）

对应能够通过单表或简单条件筛选直接完成的查询。

特点：

- 单一查询目标
- 字段含义明确
- 条件简单（如公司、年份、指标）
- 通常不需要聚合计算或复杂关联

典型 SQL 特征：

- `SELECT + WHERE`
- 简单字段查询

示例：

- 查询某公司某年的营业收入
- 查询某项费用金额
- 查询某季度净利润

------

#### 2级（中等）

对应需要进行统计计算、聚合分析或简单多表关联的查询。

特点：

- 存在统计或计算逻辑
- 涉及排序、分组、占比等分析
- 可能需要 2–3 张表关联
- 需要一定 SQL 逻辑推导

典型 SQL 特征：

- `GROUP BY`
- `ORDER BY`
- 聚合函数（`SUM`、`AVG` 等）
- 简单 `JOIN`

示例：

- 查询收入增长率
- 查询行业平均毛利率
- 查询 TopN 企业
- 查询同比/环比变化

------

#### 3级（复杂）

对应需要多步推理、复杂关联或高级 SQL 结构的查询。

特点：

- 多个查询目标或多重条件组合
- 涉及复杂时间口径
- 存在嵌套查询、窗口函数或多阶段计算
- 可能需要拆解为多个 SQL 步骤完成

典型 SQL 特征：

- 多层嵌套查询
- CTE（公共表达式）
- 窗口函数
- 多表复杂关联
- 多指标联合分析

示例：

- 同时分析多家公司多年的变化趋势
- 排名及占比联合计算
- 多指标交叉分析
- 数据校验类查询
