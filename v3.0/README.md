# FinSafe-QA V3.0

V3.0 是 FinSafe-QA 的第三阶段迭代，重点引入：

- 上下文管理模块
- 多意图自主规划模块

```text
用户问题 -> 上下文管理 -> 问题重写 -> 多意图拆解 -> 自主任务规划 -> 查询/计算/证据/图表 -> 可信输出
```

## 本地启动

```bash
python3 server.py
```

## 命令行测试

```bash
python3 -m src.engine "①找出2025年第三季度资产负债率最低的3家公司；②计算它们的流动比率；③分析这些公司偿债稳健的原因"
```

## 模块评测

```bash
python3 evaluate.py
```

V3.0 评测只针对新增模块：上下文记录、追问处理、问题拆解、任务类型覆盖和依赖编排。
