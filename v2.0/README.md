# FinSafe-QA V2.0

面向金融投研场景的可信数据分析引擎，在 V1.0 可信问数能力基础上增加分析计划、结果校验、洞察生成和自动可视化。

```text
自然语言提问 -> 分析意图识别 -> SQL 查询 -> 规则计算 -> 洞察生成 -> 图表配置 -> 可信层输出
```

## 数据源

- 数据源：AkShare / 同花顺公开财务数据
- 缓存文件：`data/finsafe_v2.db`
- 覆盖公司：10 家医药/CXO/创新药相关 A 股上市公司
- 覆盖期间：2022 年、2023 年、2024 年年度报告，2025 年三季报

## 启动 Web 服务

```bash
python3 server.py
```

打开：

```text
http://127.0.0.1:8765
```

## 命令行查询

```bash
python3 -m src.engine "比较凯莱英、药明康德、泰格医药2025年第三季度的销售毛利率，用条形图展示"
```

## 运行评测

```bash
python3 evaluate.py
```

评测脚本会生成运行结果到 `reports/`，核心结论已整理进 `【v2.0】项目评测.md`。
